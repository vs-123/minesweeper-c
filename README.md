# MINESWEEPER

  A simple minesweeper implementation in C.

  This a C port of my original C++ Minesweeper project @ https://github.com/vs-123/minesweeper

## FEATURES
- [x] Fun
- [x] Reveal Cells
- [x] Game Over/Win screen
- [x] Flags
- [x] Auto Reveal Cells with Middle Click
- [x] Timer
- [x] Icons
- [x] Coloured Numbers
